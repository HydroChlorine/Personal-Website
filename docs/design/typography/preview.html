I like the moment when a small observation opens a much bigger question. This is a place for the things I make, the questions I get caught up in, and whatever I learn along the way.

For a long article, the texture should become quiet enough to forget. A spectrum is a chemical observation and a mathematical signal. The font gives the page a particular atmosphere; the explanation still needs to do the work.

Pixelify Sans headings/navigation + DotGothic16 prose. Scientific notation should use an appropriate math face and fallbacks; this preview deliberately includes mixed-script samples above.

Planning specimen only. All four fonts are SIL OFL 1.1; the original font files and notices are in the adjacent fonts/ folder. No fonts were installed system-wide or applied to the React app. A slanted letter in this study is a synthetic oblique, not a supplied italic font.
