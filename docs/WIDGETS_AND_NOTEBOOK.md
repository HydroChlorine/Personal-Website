# Widgets and notebook

Implemented on `widgets-and-play-elements-impelmentation`, 2026-11-11.

## Notebook entries

Each post is a separate typed content file under `src/content/notes/`. The first is `2026-11-11-hello-world.ts`, exported as `helloWorld` and registered in `index.ts`. The URL is `/notebook/hello-world`.

To add a post:

1. Copy the first post to `YYYY-MM-DD-short-title.ts` and give the export a new name.
2. Set a unique `slug`, `title`, ISO `date`, `summary`, `paragraphs`, and optional subject associations (`subjects: []` is appropriate for a general personal entry).
3. Import that export in `src/content/notes/index.ts` and add it to the array. The array is sorted newest first. No route or page-component change is needed.

`NotebookPage.tsx` provides the listing and `NoteDetailPage.tsx` provides the body. Browser titles now use the note title. General entries use the campus banner; subject-associated entries use the existing subject context rules.

## My check-in

Edit `src/content/now.ts`. Values are between −1 and +1; zero means the author's usual level. Initial values selected by Lichen are mood +0.30, energy −0.50, attention −0.10, dated 2026-11-11. Set the ISO date and short note when updating. `updated: null` explicitly shows the pending/neutral placeholder state instead of claiming a live current mood.

The separate **Feelings** widget starts collapsed at every screen size. Its always-visible cyan value strip is `+0.30 / -0.50 / -0.10`; the heading expands the three instruments. Values remain in local component state when visitors adjust the controls; reset restores Lichen's check-in. The check-in note is inside the expanded panel. Motion follows the site's motion setting.

The attention scene depicts **Nyan Cat**, the character by Christopher Torres, from the reference supplied by Lichen. The sharp SVG and five pixel/chaos variants are generated by `scripts/draw-feelings-nyan.py`. Attribution appears in `public/art/widgets/README.md`, `ATTRIBUTIONS.md` and `/credits`. Legacy moth assets are unused. The image becomes smaller-resolution, blurred and eventually scrambled toward −1.

Sources: `src/components/widgets/MomentWidget.tsx`, `momentState.ts`, `src/styles/widgets.css`, and `src/content/now.ts`.

## Moon over Ithaca

Placed between Feelings and Atmosphere. `src/components/widgets/MoonWidget.tsx` draws the pixel moon and readouts; `moonState.ts` holds the display name, fixed Ithaca coordinates (42.4444, −76.4926) and America/New_York clock. SunCalc 2.1.4 provides phase, azimuth, altitude and orientation. Its v2 API returns **degrees**, with azimuth clockwise from north. The visible disk is shaded using illuminated fraction and bright-limb angle minus parallactic angle; the texture is newly drawn. Readouts update every second, with timer cleanup on unmount. The clock honors daylight saving time and does not use the visitor's timezone. No location permission or external request is needed.

The user requested dimden's original widget with little change. Its official page permits embedding, but the inspected iframe uses the visitor's location and has no documented fixed-coordinate option. This is a local interpretation retaining the compact pixel moon/readout presentation and yellow accents, explicitly credited to dimden beside the widget and on `/credits`. It does not reproduce dimden's image assets, font, or source code. SunCalc is BSD-2-Clause; full notices are in `public/licenses/THIRD_PARTY_NOTICES.txt` and `third-party-licenses/`.
